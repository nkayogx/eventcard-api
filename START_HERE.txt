## 🚀 Quick Start (5 Minutes)

### Step 1: Update Database Connection
Open: `application.properties`

Find these lines and update them:
```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/demo_db
spring.datasource.username=postgres
spring.datasource.password=password
```

Change to your PostgreSQL:
- URL: Your database server
- Username: Your PostgreSQL username
- Password: Your PostgreSQL password

### Step 2: Generate JWT Secret
Open: `application.properties`

Find this line:
```properties
jwt.secret=MySuperSecureSecretKeyThatIsAtLeast32CharactersLongForHS256Algorithm
```

Generate a strong random secret:
```bash
openssl rand -base64 32
```

Copy output and replace the value.

### Step 3: Start Application
Open terminal/command prompt:
```bash
cd "C:\Users\MDH\Downloads\Java Projects\demo"
mvn spring-boot:run
```

Wait for: `Started DemoApplication` message

### Step 4: Test It
Copy this command to terminal (replace `{token}` when you get it):
```bash
# Register
curl -X POST http://localhost:8181/api/auth/register ^
  -H "Content-Type: application/json" ^
  -d "{\"name\":\"Test\",\"email\":\"test@test.com\",\"password\":\"pass123\"}"

# Copy the token from response, then test protected endpoint
curl -X GET http://localhost:8181/api/users ^
  -H "Authorization: Bearer {YOUR_TOKEN_HERE}"
```

**Done!** ✅ System is working.

## ❓ Your Questions Answered

### "How does Spring autowire dependencies?"
When you mark a class with `@Service` or `@Component`, Spring automatically finds and injects it into classes that need it. No explicit configuration needed!

### "Why do responses get filtered?"
Security filters check every request before it reaches your code. They validate tokens, set up security context, and check authorization.

### "Why does my search return empty?"
You already fixed it! The code uses `findAllByFirstNameContainingIgnoreCase()` which is case-insensitive.

## 🆘 Troubleshooting

| Problem | Solution |
|---------|----------|
| Database connection fails | Check credentials in application.properties |
| Token rejected | Check jwt.secret is set correctly |
| 403 Forbidden | You don't have the required permissions |
| Roles not found | Run application, DataSeeder auto-creates them |
| Port 8181 in use | Change server.port in application.properties |
